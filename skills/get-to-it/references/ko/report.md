# 보고서 양식 글 (한국어)

목적: 보고 내용을 정확하고 명확하게 전달. 업무·결과·검토·주간 보고와 기안에 적용. `rules.md` 규칙에 더해 아래 기준 적용. 국내 회사에서 실제로 결재하고 공유하는 보고서 문체로 작성, 영어 보고서식 표현·번역투 금지.

- 사용자가 준 양식, 이전 보고서, 사내 예시가 있으면 그대로 적용. 없으면 마크다운 `##` 제목 아래 `-` 불릿, 들여쓰기는 2단계까지.
- 첫 절에 보고 목적이나 결론, 결정할 사항 기재. 절은 내용이 있는 것만 배치(개요 → 현황 → 문제점 → 개선 방안 → 향후 계획 → 요청 사항). 비교안과 일정은 표로 정리.
- 불릿 하나에 사실 하나. "우리는", "본 보고서는" 같은 주어 미사용. 제목을 되풀이하는 서론과 맺음 요약 금지.
- 수치, 금액, 일정, 담당자는 원문이나 사용자가 준 값만 기재. 없으면 `[금액]`, `[담당]` 자리표시. "획기적", "극대화" 같은 수사 금지.
- 사용자가 쓴 보고서는 고칠 이유가 있는 곳만 수정. 이미 회사 보고서 문체인 글은 그대로 반환.

| 영어 보고서식 표현 | 회사 보고서 표현 |
| --- | --- |
| 정산 절차에 대한 검토를 진행함 | 정산 절차 검토 |
| 관련 부서들과의 협업을 통해 일정을 확정함 | 관련 부서 협의 후 일정 확정 |
| 우리는 일정을 조정할 필요가 있음 | 일정 조정 필요 |
| 요약문, 배경, 다음 단계, 액션 아이템 | 개요, 추진 배경, 향후 계획, 조치 사항 |
