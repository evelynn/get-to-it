# long-form

Convey the purpose and the content accurately and clearly in documents, email, notices and UI copy, and keep every fact of the source when editing or translating.

`${CLAUDE_SKILL_DIR}` is the folder that holds this file. Before you write anything, read one file and follow it. It is the whole rule set for that language.

- The result is Korean: `${CLAUDE_SKILL_DIR}/ko.md`
- Any other language: `${CLAUDE_SKILL_DIR}/en.md`, applied in that language's business style

Work reports and status updates follow get-to-it's company tone instead: `${CLAUDE_SKILL_DIR}/../get-to-it/SKILL.md`. When get-to-it is on, its reply-shape rules cover only the message that hands over the result, not the result.
